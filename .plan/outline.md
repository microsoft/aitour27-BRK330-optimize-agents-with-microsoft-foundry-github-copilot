# Breakout outline

## Recommended objectives

By the end of the session, attendees will be able to:

1. Define quality, compliance, cost, and latency targets for an agent.
2. Use GitHub Copilot and Microsoft Foundry to hill-climb one system lever at a
   time against consistent evidence.
3. Use Agent Optimizer to automate candidate evaluation while retaining human
   control.

## 45-minute flow

| Act | Duration | Narrative | Demo |
|---|---:|---|---|
| Set the stage | 5 min | Caldova needs useful, compliant, economical, adaptable travel support. | None |
| Make it work: Let's build | 12 min | Ship and baseline the Contoso Travel Concierge. | Agent Loop: build and baseline with GitHub Copilot |
| Make it better: Let's climb | 12 min | Define success and manually hill-climb cost and quality. | Model Loop: rubric, routing, and trained student |
| Make it easier: Let's automate | 12 min | Automate repeatable experiments using the same evidence. | Agent Optimizer in the Foundry portal |
| Summary | 4 min | Apply the optimization playbook to other agents. | None |

## Act 1: Set the stage

- 2 min: Caldova, Contoso Travel, and the four personas.
- 2 min: model choice, weak generic benchmarks, system cost, production control,
  and drift.
- 1 min: preview Agent Loop, Model Loop, and Agent Optimizer.

## Act 2: Make it work

- 3 min: Krystal's compound trip request and success criteria.
- 6 min: recorded GitHub Copilot build/deploy/hero-request sequence.
- 3 min: Foundry traces and Insights reveal measured behavior gaps.

## Act 3: Make it better

- 3 min: Caldova rubric, fixed evidence, and the hill-climbing rule.
- 7 min: recorded Copilot/Foundry workflow for baseline, task decomposition,
  Model Router, and supported student-model experiment.
- 2 min: portal comparison across quality, compliance, cost, and latency.

## Act 4: Make it easier

- 3 min: why manual experiments cannot keep pace.
- 7 min: portal-first Agent Optimizer recording.
- 2 min: human review, promotion decision, and stakeholder payoff.

## Act 5: Summary

- 2 min: Agent Loop, Model Loop, Agent Optimizer recap.
- 2 min: representative workload, explicit targets, baseline, controlled
  experiments, and continuous automation.
